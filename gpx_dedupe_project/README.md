# GPX Route Deduper V0.1

一个可执行、有限范围的 GPX 轨迹几何去重原型。输入 GPX，产出 `cleaned.gpx`、`cleaned.geojson`、`comparison.png`、`report.json`。

## 算法

1. `xml.etree.ElementTree` 读取 GPX (当前限定恰好一段 `trkseg`)；采用 UTM 本地投影以米计算。
2. 每 10 米重新采样，在全程前 45% 和后 45% 中用 `cKDTree` 搜索空间近邻。可通过 `Config.max_tail_m` 额外限制每侧搜索距离，默认不设绝对距离上限。
3. 结合距离、反向航向和局部沿程单调匹配寻找持续重合，允许重合晚于起点出现、两侧接入行程不等。默认重合至少 150m，连续段匹配密度至少 85%，且匹配长度至少覆盖每侧待裁行程的 70%。这些是几何启发式，不是道路身份或交叉安全保证。
4. 符合条件后保留中间主体闭环，**裁掉两侧整个接入行程，包括未匹配部分**，不是只删一次重复通过，也不保证保留全部唯一路段。切点间距不超过 20m 才允许中点闭合。
5. 未发现尾巴时，检测 2–6 圈同方向、完整、近似等长的全线周期匹配。默认单圈至少 450m，因此标准 400m 跑道重复圈不在默认支持范围。
6. 没有满足规则时保持原样，不代表不存在重叠；内部回头支路没有专用处理。近似对称纯往返有保留保护，但没有“自动保留单程”能力。

### 本机样本与效果边界

`34044834.gpx` 的先前实测：46.204km / 1044 点 → 44.166km / 1008 点，首尾切点约 16m 偏差以中点拼接。这只是单个样本，不是普遍去重准确率，也不是道路导航级地图匹配。

`37002172.gpx` 暴露了旧规则的问题：从起点开始的短暂不匹配、2.5km 搜索上限和两侧路程对称要求，都会阻断后续持续重合的识别。现在用局部连续匹配与覆盖率约束处理此结构。报告中的 `prefix_matched_m` 是一侧匹配长度估计，`unmatched_access_m` 是两侧被裁行程中缺少反向匹配证据的长度估计，不能当成已验证的独有道路长度。

### 回归覆盖

`tests/test_route_dedupe.py` 包含原有检测器检查，以及完整处理与导出检查：长尾巴、较晚开始且两侧不等长的接入行程、单圈、2 圈、开放路线、纯往返、8 字、半径外平行道路、过短重合、覆盖率不足、切点超限。可选真实样本测试需要 `examples/37002172.gpx`，缺少私有文件时跳过。合成测试通过不代表任意 GPS 漂移、立交或路网拓扑均已验证。

### 已知限制

- 不支持把任意多分叉、多次交叉或重叠支路拆成无重复道路图；该问题需要独立的路段级匹配、交点切分与图重构模块。
- 不能跨越单个 GPX 的多个轨迹段：直接合并可能跨越轨迹中断、产生虚构道路。
- 缺少道路平行线和道路等级语义，约 10–20m 的 GPS 近邻可能是不同物理道路。导航前需对接地图匹配/路网校验。
- 一次标准闭环不应该被删除。重复整圈判定只在全线近似周期重复时启动。
- 处理后的 GPX 不保留原始时间戳（裁剪、重定位后原始时间语义不再成立）；可保留原有海拔。
- 压缩长度指实际运动轨迹长度减少，不代表删去了 2km 独有的道路几何。

## 路线拓扑、处理目标与成功比例

完整的逐类说明见本地 `/about`：包含 12 类结构、识别依据、难点、当前行为与处理前后示意。结构可以叠加，不是软件已经实现的 12 个分类器。

| 结构 | 识别依据与难点 | 当前 / 规划处理及前后对比 |
|---|---|---|
| 开放单程 | 端点分离容易检查，不代表内部无重复 | 当前无规则命中则 `A→B→C` 不变 |
| 简单闭环 | 闭合不等于简单环，需要排查重复边 | 当前普通 `A→B→C→A` 保留 |
| 纯往返 | 折返点两侧反向对齐，噪声会破坏对称 | 当前尝试安全保留 `A→B→A`；规划取 `A→B`，会改变终点 |
| 尾巴＋环 | 首尾持续反向重合、覆盖率充分 | 当前 `S→A→环→A→S` 变成 `A→环→A`，接入道路被移除 |
| 不等长接入＋环 | 重合开始较晚，局部进度一致但整体不对称 | 当前覆盖率达标可取中间环；未匹配接入也可能一起被裁 |
| 完整同向重复圈 | 2–6 个近似等长周期、相位坐标一致 | 当前 `环×k` 目标变成一圈；圈数可能误计，标准 400 米不在支持范围 |
| 残圈 / 混向圈 | 固定周期假设失效，需要局部对齐分段 | 专用处理未实现；规划分别保留完整环和残段，不保证当前原样 |
| 内部回头支路 | 任意位置持续反向匹配，区分支路与真环 | 规划 `A→B→C→B→D` 取 `A→B→D` 或保留 AB、BC、BD 道路图；当前未去重 |
| 8 字 / 相接双环 | 交点需验证为真实路口，不能把点交叉当重复边 | 当前有保留样本；规划保留双环、分环导出或按目标选主环 |
| 共享走廊 / 多分叉 | 边聚类、交点切分、通过次数；存在多解 | 规划分别输出连续主路线与完整唯一路网，当前未实现 |
| 平行路 / 立交 | 几何近邻不足以证明同一道路，需要路网语义 | 安全目标是保留不同道路；当前可能误裁 |
| 断点 / 多段 / 漂移 | 先检查段边界和数据质量，不能虚构连接 | 多 trkseg 当前拒绝；单段异常点清洗与分段处理未实现 |

主环提取、单程保留、全部唯一边覆盖、连续可导航路线是不同目标。比如树形支路要走到尽头再回来，重复通常不可避免；不能同时保证全覆盖、闭合、绝不重边。当前仅提供两类几何裁剪，未提供处理目标选择或路网重构。

### 352 个确定性合成样本的实测（不是实际 GPS 成功概率）

默认 Config；每个几何变体 × 每轴独立高斯扰动 σ=0/1/3/8 米 × 两个固定种子（1729、104729）。端点同样扰动；0 米两个种子是重复对照，不能当作独立实测。没有时间相关 GPS 漂移、真实标注集、置信区间；不要混合类别报总体准确率。

| 样本族 | n | 正类识别正确 | 处理符合目标 |
|---|---:|---:|---:|
| 开放三边矩形，边长 200/500/1000 米 | 24 | N/A | 保留 24/24（100%） |
| 单圈，半径 100/200/500 米 | 24 | N/A | 保留 24/24（100%） |
| 同向 2–6 圈，三种半径 | 120 | 65/120（54.17%） | 65/120（54.17%） |
| 400 米周长圆的 2–6 圈，非体育场椭圆 | 40 | 3/40（7.5%） | 3/40（7.5%），不算已支持 |
| 尾巴＋方环，边长及尾巴各 300/600/1200 米 | 24 | 24/24（100%） | 21/24（87.5%） |
| 1.0/1.2 公里不同接入＋3.5 公里公共尾巴＋16 公里环，缩放 0.5/1/1.5 | 24 | 20/24（83.33%） | 19/24（79.17%） |
| 直线纯往返，单程 500/1500/3000 米 | 24 | N/A | 保留 15/24（62.5%），9/24 误裁 |
| 方环内部支路，环边长 400/800/1600 米、支路 250/500/1000 米 | 24 | N/A | 保留 24/24（100%），并未去重 |
| 8 字，x=a·sin(t)，y=.625a·sin(2t)，a=200/500/800 米 | 24 | N/A | 保留 24/24（100%），并未识别双环 |
| 4 公里平行接入路，间隔 10/25/50 米，连接 16 公里环 | 24 | N/A | 保留 16/24（66.67%） |

正类识别要求 tail/laps 类型正确且圈数完全正确；保留类未触发检测器不能算识别该拓扑。正确处理还要求正确 method：保留类坐标数组完全一致，裁切类须闭合、与理想单环的双向采样距离不超过 30 米、长度差不超过 max(60 米, 5%)。参考长度取带噪观测的单圈/中间环，不要求未实现的去噪。

- 同向 2–6 圈按 σ=0/1/3/8 米的识别及正确处理为 30/30、30/30、5/30、0/30。独立扰动增长观测弧长并破坏相位，不能从干净圆推断真实 GPS 鲁棒性。
- 尾巴＋方环正确处理为 6/6、6/6、6/6、3/6；不等长接入为 6/6、6/6、6/6、1/6。
- 纯往返安全保留为 6/6、6/6、2/6、1/6；保护在有噪声时并不可靠。
- 10 米间隔的不同平行道路 8/8 误裁，25/50 米各 8/8 保留。几何距离无法证明物理道路相同。
- 400 米周期因默认最小周期 450 米而不受支持：11/40 触发裁圈，仅 3/40 正确。部分干净偶数圈会被当成较长组合周期；偶然成功不能算完整能力。

### 真实成功率仍未知

已运行的 `34044834.gpx` 与 `37002172.gpx` 是针对性案例，不是随机抽样真实标注集，不能算 100% 成功率。可信评估需要按拓扑、设备、环境、定位误差分层采样，人工标注道路身份与理想输出，独立测试，分别统计召回率、精确率、误删率、漏删率、边覆盖和连通性，而不是只统计 method 命中或 unchanged。
