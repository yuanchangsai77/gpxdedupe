# 原始轨迹密度与覆盖代表筛选

本模块独立于道路规划运行：只读原始路线库，向独立覆盖库写入统计与决策，不删除轨迹、不执行语义去重、不调用规划器。重建失败不再使一条有价值的历史轨迹失去展示机会。所有阈值都是待校准实验参数，不代表通行认证。

## 密度及贡献

采用标准纬线30度的球面等面积圆柱投影。相邻GPS观测之间以不超过20米的间隔作中点积分，每个样本按代表长度加权，避免原始采样频率影响。100米和500米网格直接统计；5000米网格从对齐的100米格按路线汇总，重新统计不同路线数，长度守恒。5公里为格宽，单格25平方公里。

- 累计长度密度：格内轨迹累计公里数/平方公里；往返和跑圈正常增加。
- 不同路线数密度：格内不同路线数/平方公里；同一路线在格内重复经过仍计一条。
- 路线对网格贡献：该路线格内长度/全部路线格内总长度。
- 网格对路线贡献：该路线格内长度/该路线统计总长度。

连续观测超过1000米的间隔不跨接，记录排除长度。此规则也可能排除真实低频采样轨迹，因此标记待复核而非认定无效。密度是库内分布，不是独立用户数或真实人流量；精确几何哈希未抵扣重复转载。中点积分在格边界有误差，未完成平移敏感性实验。

## 正式实验选择流程

`coverage_selection.py` 的 selection-2 按100米格选择：

1. 原始统计长度大于零且没有排除间隙，才通过当前基础检查。没有加入时间速度、漂移、可通行性检查。
2. 基础检查通过且已有 candidate 状态及非空重建字段的路线固定保留，使用已有重建候选。review/failed/未重建等状态采用整条原始轨迹，不做几何拼接。
3. 其余经过不同路线数不超过2的稀疏网格的基础可用路线全部保留。少量经过也会触发，此策略保守，可能保留很多路线。
4. 利用倒排及惰性堆，依次选择对已选集合新增覆盖最大的路线，直到至少覆盖95%的基础可用网格。每格得分为该路线格内长度与格宽的较小值，防止重复跑圈支配选择；保护规则可使最终覆盖远高于目标。
5. 其余路线降低默认展示优先级，保留原记录和理由，不认定重复。无方向、环线或往返结构前置检查。

固定保留优先于稀疏保护。顺序和入选时新增覆盖长度、稀疏长度、理由及策略参数均保存。这里衡量网格覆盖，不是道路覆盖；同格平行道路可能混淆，不用于语义去重。内存随覆盖关系增长，尚未验证600万条规模。

## 数据与运行

在 `gpx_dedupe_project` 下：

```bash
python3 -m route_semantics.coverage --source outputs/chengdu-city/city.sqlite3 --output outputs/chengdu-city/coverage/pilot.sqlite3 --limit 3000
python3 -m route_semantics.coverage_rollup --coverage outputs/chengdu-city/coverage/pilot.sqlite3
python3 -m route_semantics.coverage_selection --source outputs/chengdu-city/city.sqlite3 --coverage outputs/chengdu-city/coverage/pilot.sqlite3
python3 -m route_semantics.coverage_view --source outputs/chengdu-city/city.sqlite3 --coverage outputs/chengdu-city/coverage/pilot.sqlite3 --output outputs/chengdu-city/coverage/index.html
```

limit是按源库ID升序取前N条，不是随机样本。增加limit可幂等扩展，每路线事务支持断点续跑；不能通过降低limit缩库。源身份和逐行摘要校验不一致时拒绝。扩库后清除派生尺度贡献，必须重新汇总、筛选再导出。未完成索引禁止筛选，旧筛选路线数不符时拒绝导出。请串行执行上述步骤；不支持并发修改覆盖库，原始库应保持固定快照。

独立库包含 routes/contributions/cells、两个贡献指标视图、selection_runs/decisions。后者追加决策修订，仅完成版本供页面使用。`coverage.py` 中保留初始无质量门槛的 select/shortlist 作为实验基线，命令行会生成该基线；它不用于混合页，正式实验选择必须执行 coverage_selection。动态派生和导出文件不进入Git。

## 页面

导出HTML内嵌当前样本及展示简化几何，可直接打开文件，也可用仅本机静态服务查看。在线高德底图使用与已有页面一致的坐标转换；底图不可用时轨迹和网格仍可显示。不调用付费路径规划。

- 全部原始：当前样本全部原始轨迹。
- 覆盖代表原始：当前已选集合，全部使用原始轨迹。
- 覆盖代表混合：同一已选集合，紫色采用重建候选，其余使用历史原始轨迹。

密度始终基于全部原始样本，不随展示集合变化。默认5公里网格仅观察宏观密度，筛选仍按100米格。支持格内贡献表、单路线理由、平移、鼠标位置缩放。小样本内嵌页面未设计为全量加载，下一步需按视窗加载。

## 已验证与限制

成都前3000条：2709条默认保留，333条重建候选、2376条原始；其余291条降低展示优先级。覆盖126009/126031个100米样本网格；5000米有覆盖网格731个。这不是成都全量分布，不能外推稀疏度或保留比例。

测试覆盖采样密度近似稳定、往返长度、观测间隔和分段、幂等续跑、拒绝参数变化与缩库、重建固定保留、稀疏保护、密集重复降优先级、汇总长度守恒、过期筛选拒绝导出、三模式浏览器检查。尚未完成全量统计、人工准确率评估、独立来源计数、连续独有段分析及完整原始轨迹质量模型。
