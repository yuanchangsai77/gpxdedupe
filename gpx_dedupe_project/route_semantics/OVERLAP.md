# 高密度重建路线：独有道路覆盖筛选

## 作用范围

只对密度规则当前选中、且采用可靠重建几何的路线做覆盖筛选。低密度原始、高密度空格补充的原始都不参与比较，也不被隐藏。全部原始模式仍保留全部证据。当前默认密度阈值10时，输入4900条高密度重建，原始470条不动。

这是默认展示优先级筛选，不是证明两条路线语义等价，不删除原始或规划结果。旧的严格等价实验可以独立关闭。

## 如何认定重叠

以完整规划几何为依据，不使用80米显示抽稀或GPS邻近距离：

1. 在同路网、同规划活动模式内，把坐标统一到1e-6度精度。
2. 为每段建立无方向的精确直线键；同一直线上的部分交叠按全部端点切成共用原子路段。
3. 只有真正重合的区间共享原子路段。平行路、河流两岸不会仅因相近而合并；点交叉不算长度覆盖。
4. 精确共线匹配偏保守：不同几何版本或取整产生的微小非共线可能漏识别，不把它们强行吸到一起。

本指标按无方向的物理道路覆盖衡量。同一路线重复经过的路段在物理长度中只计一次，防止跑圈或往返支配覆盖排序；另存实际行进总长度。保留的完整路线仍保持原顺序和方向，但被降低展示优先级不表示其方向/行程意图完全相同。

## 指标和筛选

- 全体重建下独有比例：没有被其他本轮重建覆盖的物理长度/本路线物理覆盖长度。
- 相对保留集合的独有比例：本路线未被最终保留的其他重建覆盖的物理长度/本路线物理覆盖长度。
- 最长连续独有段：沿实际规划顺序计算，不能把分散漂移拼成一段。
- 覆盖来源：主要由哪些保留路线覆盖及各自重叠长度。前5个来源分别计量，彼此可能重合，不能直接相加当联合覆盖。

先保护环线，再逐步选择新增覆盖最多的路线，选择后立即更新其他路线的贡献。重复覆盖不能导致两条路线相互依赖而一起消失。覆盖完成后反向检查冗余，并重新纳入达标的落选路线，逐轮稳定最终集合。

默认采用**热门精简模式、50%独有比例硬门槛**：非保护路线只有在独有物理覆盖比例达到门槛时才保留。独有总长度500米、最长连续独有段300米只显示为指标，不再绕过比例门槛。这是为减少热门城区默认展示数量而主动放弃部分道路覆盖，不是保证全路网覆盖。

页面同时保留**覆盖优先模式**：独有比例、独有总长度500米、最长连续独有段300米任一满足即可保留，对应此前的保守策略。模式和比例共同参与缓存键，切换不会误用另一套结果。页面可比较5%、10%、20%、30%至90%，默认50%；门槛尚未人工校准。

环线保护：首尾距离≤30米，且存在足够的闭合道路核心，或行进长度足够而物理覆盖/行进长度≥80%的近闭环。利用道路图去除叶子支路后判断闭合核心，不只看起终点接近；普通原路往返不因此变成环线，多圈真实闭环仍保护。复杂分段保留，不自动拆拼后淘汰。保护不等于已完成所有路线形状分类。

最后沿用高密度区域保护：如果隐藏某条会使一个高密度5公里格失去最后一条已选路线，则额外保留。这里只是区域级检查，不能证明所有道路都覆盖。该保护触发时重新计算相对最终集合的指标。

## 成都实际结果

对默认4900条高密度重建，闭合/近闭合保护497条：

热门精简模式（只有比例达标才保留，另有保护例外）：

| 独有比例门槛 | 保留重建 | 筛下 | 保留重建物理道路覆盖 |
|---|---:|---:|---:|
| 20% | 3883 | 1017 | 94.78% |
| 30% | 3450 | 1450 | 90.90% |
| 40% | 3138 | 1762 | 86.93% |
| 50% | 2805 | 2095 | 82.24% |
| 60% | 2572 | 2328 | 78.33% |
| 70% | 2326 | 2574 | 73.58% |
| 80% | 2132 | 2768 | 68.76% |
| 90% | 1948 | 2952 | 61.14% |

修复后默认保留2805条重建＋470条原始，共3275条。497条环线保护；区域保护由最终集合重新校验。覆盖优先10%保留4553条重建、99.25%物理覆盖。

P1修复：不能只删除已选路线。每轮删除后，重新计算所有落选路线相对当前集合的独有覆盖，补回达标路线，直到选中和落选两侧均满足规则。默认档3轮稳定；重纳操作45次（不是最终净增条数），最终比旧实现多保留34条。区域保护也参与稳定循环，避免事后补入路线破坏其他路线的判断。超过资源上限或出现循环明确失败，不输出伪成功。

保留物理覆盖82.24%，主动筛下约1603.68公里物理覆盖。这不是语义等价去重、全市道路覆盖率或导航准确率。保护路线允许低于50%；原始路线完全不参与覆盖筛选。全部原始和重建数据仍保留。

本轮已接入正式delivery入口，页面与离线文件使用同一最终策略；默认compact/50%，可通过--overlap-mode off关闭，或--overlap-mode coverage --overlap-fraction 0.1选择覆盖优先。

## 文件和运行

```bash
python -m route_semantics.overlap_index --source outputs/chengdu-city/city.sqlite3 --coverage outputs/chengdu-city/coverage/full.sqlite3 --output outputs/chengdu-city/coverage/overlap-index.json
node route_semantics/overlap_report.cjs outputs/chengdu-city/coverage/overlap-index.json outputs/chengdu-city/coverage/overlap-selected-ids.json outputs/chengdu-city/coverage/overlap-report.json
python -m route_semantics.coverage_view --source outputs/chengdu-city/city.sqlite3 --coverage outputs/chengdu-city/coverage/full.sqlite3 --overlap outputs/chengdu-city/coverage/overlap-index.json --output outputs/chengdu-city/coverage/full.html
```

传入--coverage会同时生成overlap-selected-ids.json，从density_decisions中读取selected=1且geometry_kind=rebuilt的编号数组。overlap-report.json保存热门精简与覆盖优先两种模式5%～90%对比，以及默认热门精简50%档逐条指标，旁边CSV便于人工查看；overlap-display-report.json是带区域保护和可选严格去重后的页面计数。源快照不一致时拒绝导出旧索引。

正式导出会将最终策略写入独立输出目录的density_decisions和overlap_metrics，并同步CSV、NDJSON、GeoJSON、报告和HTML；原始源库只读。浏览器调参仅影响当前页面，需按相同参数重跑delivery才更新离线文件。

## 限制

没有把短桥、入口、POI等语义价值纳入判断，小独有段仍可能有价值。循环和活动规则待人工复核；几何精确区间会漏掉部分近似重叠。现有质量候选不等于导航认证。当前以保留理由和指标供审查，不以压缩数量作为准确率证明。
