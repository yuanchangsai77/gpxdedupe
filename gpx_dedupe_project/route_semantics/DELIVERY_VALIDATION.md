# 算法包验收记录

版本：route-density-delivery-1。验收日期：2026-11-26。

## 环境与方式

Linux/WSL，Python 3.11.15，NumPy 2.4.6，Pillow 12.2.0，Node.js 26.1.0。浏览器检查使用本机Edge/Playwright。

将ZIP解压到独立临时目录，确认模块实际从解压目录导入；在解压目录编译数值内核、运行测试，并使用包内14条明确标记的合成轨迹执行完整导入和筛选导出。没有依赖仓库中的真实轨迹、SQLite库或已有本机图缓存。

## 结果

- 64项Python单元测试通过。
- 密度策略、重建显示去重保护、动线三组Node测试通过。
- 合成样例14条输入，最终3条原始路线，其中1条补充高密度空网格。
- 已导出CSV、入选清单、3要素完整GeoJSON、最终报告和HTML。
- 验证再次运行不同阈值和低密度门槛，参数与结果一致。
- 验证本轮失败状态明确记录，即使旧成功报告还存在也不误标成功；无效GeoJSON分段拒绝导出且保留旧有效文件。
- 打包采用明确文件清单，验证同一源码打包校验值稳定、拒绝越界符号链接及错误输出扩展名。
- 验证运行前后输入库的原始记录、状态及关联表逻辑内容不变；不以SQLite检查点可能改变的文件物理字节作为唯一依据。
- 浏览器以file方式打开解压包生成的页面，阻断外部底图，轨迹、初始参数、阈值切换、长度参数保护和选线均正常，没有页面脚本错误；默认去重禁用。
- ZIP完整性检查通过；manifest逐文件SHA256核对通过；不包含真实数据库、OSM、JAR、二进制内核或Python缓存。

## 验证边界

本次没有重启GraphHopper或构建新路网，未在接收方机器上验证规划服务。成都42130条的统计和重建结果来自之前真实实验，不能用14条合成样例证明真实准确率。

ZIP不含运行时和依赖wheel。依赖安装需要接收方网络包源或另备离线依赖。原生Windows/macOS、其他Python/Node版本、生产App接入和600万条规模未在此包验收中验证。

该记录对应当前交付代码；后续修改代码后应重新验收。ZIP整体校验值见压缩包旁的.sha256文件，逐文件清单在包内manifest.json。
