# 重建路线的保守等价去重

## 范围

仅处理当前全量密度默认集合中采用重建表达的4900条路线。低密度原始与高密度空格补充的原始路线不去重，不改原始库、规划结果或密度决策。独立库保存等价组、来源路线编号、代表编号及逐对解释；这里统计的轨迹记录数不是独立用户证据数。

第一版只自动合并有明确证据的同拓扑路线，不把大范围网格重叠或同POI视为重复。尚未实现完整路线族、变体聚类或近似语义召回。

## 候选与判定

1. 仅限单原始分段、单重建几何。缺失完整有向边证据、分段不明或多段的路线保留独立，记录原因。
2. 路网版本、提取算法版本、原始活动编码、规划活动、闭合类别和**有序有向边序列**组成哈希候选键。不做4900条全量两两比较。
3. 窗口边界切分的连续同边遍历合并，非连续重复遍历保留。起终点距离≤15米暂判闭合，闭合序列允许循环平移，不反转方向；同一闭合边的首尾部分归为一次完整遍历。多圈仍保留重复边序列，不能和单圈合并。
4. 候选还必须同时满足：重建长度差≤30米且相对差≤1%；非闭合起点、终点对应距离各≤15米；两个方向的完整顶点到对方线段距离最大≤8米、P95≤3米。方向和经过次数先由有向边序列约束，几何检查不替代拓扑检查。
5. 同边序列可能对应不同端点截取或不同实际长度，仍需长度与几何验证，不能仅凭道路序列相同就合并。
6. 簇内新成员必须与**每个已有成员**通过检查，避免A≈B、B≈C导致A与C误合并。按历史重建走廊误差较小、编号较小的顺序确定代表。

以上为保守实验阈值，未通过人工标签校准；没有准确率结论。近似道路序列、有小端点变化、近闭环等可能漏合并，不应为了增加压缩率放宽到未经验证的标准。

## 显示与覆盖保护

保持原页面形式，新增“合并等价重建”复选框，默认勾选，可关闭对比。动态阈值改变时，仅在当前仍采用重建的同组成员中选代表；某成员改为低密度原始后，不被当作另一个重建成员的展示代表。

隐藏重复前检查当前高密度格的已选路线数。如果隐藏后会让任何高密度格失去最后一条已选路线，则额外保留该重复并计入区域覆盖保护。该检查与密度方案一致，只是5公里区域级，不保证道路级覆盖。手动选择被合并记录仍可查看，其说明指出代表路线编号。

## 数据与命令

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -m route_semantics.rebuilt_dedup --source outputs/chengdu-city/city.sqlite3 --coverage outputs/chengdu-city/coverage/full.sqlite3 --output outputs/chengdu-city/coverage/dedup.sqlite3
python3 -m route_semantics.coverage_view --source outputs/chengdu-city/city.sqlite3 --coverage outputs/chengdu-city/coverage/full.sqlite3 --dedup outputs/chengdu-city/coverage/dedup.sqlite3 --output outputs/chengdu-city/coverage/full.html
```

去重入口限制单CPU、2GiB，结果事务追加修订。runs记录版本、阈值和源快照；members保存代表关系和通过依据；pairs保存每次精细比较的通过或拒绝指标。源几何、定义、活动或图版本改变时，页面快照校验拒绝旧去重结果，需要重新运行。密度或规划仍在变化时不要并发运行这些命令。

## 本次真实结果

4900条输入，4878个哈希候选桶，25次精细检查，合并1条等价重复：21404由20980代表；另24次候选比较未满足严格条件，继续独立展示，不能把它们直接称为已确认变体。计算11.08秒，不含页面导出或浏览器验证。

只是严格第一版的结果，不代表其余4899条全部语义不同。下一步可增加有序边序列近似召回、端点小幅变化和人工正负样本评估，再决定是否合并更多；原始道路/几何证据保持可追溯。
